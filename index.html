Mods

Mods are JSON files that add or replace ships, weapons, crew races, enemies, events and rules. They are saved in this browser and apply when you start a new run.

Paste mod JSON instead
    Mod format and example

    Top-level keys: name (required), version, author, rules, races, weapons, ships, enemies, events, remove. Each list is an array of objects with an id. Using an id that already exists replaces that item. Weapon types: laser, missile, ion, beam. Systems: shields, engines, oxygen, weapons, medbay, piloting. Ships may give rooms as {"sys":"shields","x":0,"y":0,"w":2,"h":2} grid cells, or leave them out for an automatic layout.
