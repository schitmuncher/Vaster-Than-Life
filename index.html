Mods

Mods are JSON files that add or replace ships, weapons, drones, augments, crew races, enemies, sectors, events and rules. They are saved in this browser and apply when you start a new run.

Paste mod JSON instead
    Mod format and example

    Top-level keys: name (required), version, author, rules, races, weapons, drones, augments, ships, enemies, sectors, events, remove, script. Each list is an array of objects with an id; reusing an existing id replaces that item. The README in the GitHub repo documents every field.
